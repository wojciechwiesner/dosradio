# AmbiRadio release checks

Branch `ow/ambi-release-grok`, integrated on top of `018ee86`. The orchestrator deploys; this branch does not.

## What was integrated

Merged in order, each with its own merge commit: `ow/ambi-integrate-w1` (3eb1e23, itself containing the rebrand,
the Classic redesign and the entry wizard), `ow/ambi-mixer-fix` (c7ed6bf), `ow/ambi-orbita-sota` (d83827d),
`ow/ambi-fix-presence-dedication` (636059d), `ow/ambi-hosts-soul-comments` (48edf00).

Overlaps were resolved by ownership, not by taking one side wholesale:

- Classic redesign owns layout and styles (`index.html`, `src/ui/dosradio.css`). Later branches add elements into it
  (the start notice, the "Komentarz na antenę" button, the comment feed) instead of restoring the old player.
- The rebrand owns brand strings, the 6 h "pełny dostęp" trial wording and USD prices. Orbita i18n keeps those and
  gains the calm-view, comment and tagline strings.
- `server/app/hosts.py` keeps the persona field, the OG share page keeps the request host and adds the `k` token,
  and the Orbita demo API keeps the USD billing fixture.
- `public/orbita.html` is generated by `node orbita/build.mjs` and was rebuilt from the merged sources after each
  conflict, never hand-merged.

## YouTube audio clipping: off

Cutting and rebroadcasting YouTube audio is disabled unless `DOSRADIO_YOUTUBE_CLIPS=1`. With it unset:

- `POST /radio-api/plus/pill`, `POST /radio-api/plus/pills/batch`, `GET /radio-api/plus/pills`,
  `GET /radio-api/plus/pill/{id}` and `GET /radio-api/plus/pill/{id}/{file}` return 410 before any job is created or
  any file is read. `download_audio` raises before yt-dlp is called.
- Cached pills already on disk are left where they are. They are unreachable, not deleted.
- A custom-radio pill whose URL points at YouTube is rejected with 410. Article links and plain notes are kept.
- The text "pigułka wiedzy" drop (`POST /radio-api/social/drops`, kind `pill`) and public RSS podcasts are unchanged:
  they summarise a web page or a feed, they never download YouTube audio.

The Classic pill form, the Orbita podcast pane, the Plus plan lists (PL/EN/RU) and the showcase host script no longer
offer or promise YouTube clips.

## Public host

`ambiradio.com` currently does not resolve and its RDAP record returns 404, so it cannot be the live host yet.
`https://dosradio.theones.io` answers HTTP 200 and is the working host. The public base URL is already configurable:
`DOSRADIO_PUBLIC_BASE_URL` (default `https://ambiradio.com`, falling back to the older `DOSRADIO_PUBLIC_URL`) feeds
share links, e-mail and alerts, while OG share pages use the request's own host, so both domains work without a code
change. Nothing here changes DNS. Set `DOSRADIO_PUBLIC_BASE_URL=https://dosradio.theones.io` until the new domain
resolves, and shared greetings and absolute links keep working.

## Checkout

A plan is buyable only when `DOSRADIO_PLUS_PRICE_USD` or `DOSRADIO_PLUS_AI_PRICE_USD` names a Stripe price that is
active and bills exactly the amount on screen (299 or 699 US cents, monthly). Otherwise checkout returns 503 and
creates no session. The yearly prices ($29.90 and $69.90) are display-only and have no checkout.
`/radio-api/billing/status` reports `checkout_available` per plan. The old `DOSRADIO_PLUS_PRICE_PLN` is not read, so a
PLN price can never be charged behind a dollar label.

## Sensitive boundaries reviewed

- **Listener identity.** Presence uses the shared `client_id` before cookies and IP, rejects unknown fields, and hashes
  the session cookie before it reaches the admin table. The listener's email and user id come from the session, not
  from the page (`server/app/auto_ramowka.py`).
- **Usage limits.** Free Plus stays at one new podcast per Warsaw day (`server/app/podcast_quota.py`); paid Plus is
  unlimited. The 6 h trial grants Plus features but not the paid-tier limits.
- **Dedication pass.** `GET /radio-api/dedications/{token}` sets a signed `dr_ded` cookie valid 10 min from the first
  open of that link from that address, never extended, and `require_access` accepts it only for that recipient and
  window (`server/app/dedications.py`, `server/app/auth.py`).
- **Comments (UGC).** `POST /radio-api/comments` caps length at 280, strips links, e-mails, phones and handles, checks
  an abuse list and an optional cached LLM score, and rate-limits per actor and per IP. A comment is scored and queued,
  never marked aired before the break plays it, and the readout is capped per station per hour
  (`server/app/comments.py`, `server/app/moderation.py`).
- **Podcast URL fetching.** `server/app/url_extractor.py` refuses loopback, link-local and private addresses before
  fetching, and the social drop path reuses it.

## Open release blockers

- `ambiradio.com` has no DNS (RDAP 404). Until it resolves, production must set
  `DOSRADIO_PUBLIC_BASE_URL=https://dosradio.theones.io` or outgoing links point at a dead host
  (`server/app/config.py:19`).
- Stripe prices are not configured in this tree, so checkout is off. A release that takes payment needs
  `DOSRADIO_PLUS_PRICE_USD` and `DOSRADIO_PLUS_AI_PRICE_USD` pointing at prices of 299 and 699 US cents monthly, plus
  `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` (`server/app/billing.py`).
- YouTube pills stay off. Turning them on is a deliberate decision (`DOSRADIO_YOUTUBE_CLIPS=1`), not a default.
